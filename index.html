Cách cài đặt

Chỉ một file — không cần giải nén, không cần quyền Admin.

Tải file cài đặtBấm nút “Tải xuống” để nhận file CaiDat_VNTienIch.vbs (chạy được ngay).
Nhấn đúp vào fileMở thư mục Downloads, nhấn đúp file vừa tải. Nếu Windows hỏi, chọn “More info → Run anyway”.
Bấm Đồng ýChương trình tự cài vào máy và tạo lối tắt ngoài Desktop + menu Start.
Dùng ngayMở “VN Tiện Ích” từ Desktop hoặc menu Start.
Gỡ cài đặt: vào Control Panel → Programs chọn “VN Tien Ich” → Uninstall; hoặc mở menu Start → VN Tien Ich → “Go cai dat”.

Hỏi đáp

Có cần giải nén không?
Không. File tải về là bản cài đặt chạy trực tiếp, nhấn đúp là cài.
Có cần quyền Administrator?
Không. Phần mềm cài vào thư mục cá nhân của bạn.
Có an toàn không?
Chạy hoàn toàn ngoại tuyến, không gửi dữ liệu đi đâu. Bạn có thể gỡ bất kỳ lúc nào.
Trình duyệt báo chặn file .vbs?
Hãy chọn “Giữ / Keep” khi tải. Đây là cảnh báo chung cho mọi file script.

Sẵn sàng dùng thử?

Tải xuống miễn phí, cài trong vài giây.
